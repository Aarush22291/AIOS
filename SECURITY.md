# Security Policy

Security is a core part of AIOS because the project involves AI-generated actions, tool execution, filesystem access and eventually operating-system-level capabilities.

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities before they have been investigated.

For now, security issues should be reported privately to the project maintainers.

Include:

* Description of the vulnerability
* Steps to reproduce
* Affected component
* Potential impact
* Suggested mitigation, if known

## Security Principles

AIOS follows these principles:

* Least privilege
* Explicit capabilities
* Sandboxed execution
* Human control
* Auditable actions
* Verification of important operations
* No implicit access to secrets
* No assumption that model output is trustworthy

## Scope

Security considerations will become increasingly important as AIOS progresses from a desktop application toward a Linux runtime and operating system.

Security requirements may therefore evolve throughout the project roadmap.
